响应速度p99 ≤ 500 ms

订单完成速度p99 ≤ 5 秒

有效购买对应的数据库订单完成，从每笔请求发起时计时。

请求可靠性错误率 ≤ 0.1 %

有效购买和重复购买分别检查；重复购买按预期拒绝不算错误。

稳定容量：须同时满足上述目标，订单最终全部完成、积压不持续增长，并通过样本与轮次检查。

实验方法与阅读说明
延迟与降幅p99 表示约 99% 的响应不超过该时长。先计算相同压力、同一轮两种方案的降幅，再汇总中位数与范围。图中 p99 为各轮 p99 的中位数，不是合并请求的 p99；范围不是置信区间。
代表档位延迟摘要选择双方均达标的最高已测共同压力，不挑降幅最大的点。其他档位保留在曲线和测量明细中；对照未完成时不生成降幅。
容量边界实心点是已证实通过档位，空心点是有效测量中未达标的档位。已测档位增幅比较两个最高通过点；增幅范围由通过 / 未达标边界推导，不是置信区间。发压无效、样本不足与观测中断不构成失败上界。
适用范围Redis 过滤实验使用固定混合流量，异步化实验使用全有效购买；两组收益不能直接相乘。完成期限从每笔请求发起时计算；突发段和整场计数按标注区分。
