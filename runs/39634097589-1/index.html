方法与适用范围

同一 runner 内交替配对，记录机器型号、镜像、配额和源码。GitHub Actions 每次机器性能可能不同，跨运行的绝对 RPS 与延迟不可直接归因于代码变化。固定负载只回答此条件下的收益，不推断最大容量。发压有效性、业务一致性与服务质量分别判定。原始数据见 performance-evidence artifact；每点 result.json、timeline.csv 和请求/提交证据可追溯。

闪铺 · GitHub Actions 单机受限资源测量CPU 资源设置不等同于独占物理核或线上容量。
